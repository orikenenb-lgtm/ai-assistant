# Bundled fonts

`DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` are copied unmodified from the Debian
`fonts-dejavu-core` package (upstream: https://dejavu-fonts.github.io/). They are
bundled so the Hebrew PDF export (reportlab) renders identically on every host.
