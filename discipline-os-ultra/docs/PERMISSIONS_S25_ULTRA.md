# מדריך הרשאות – Samsung Galaxy S25 Ultra

> **הערה חשובה:** שמות התפריטים כאן מבוססים על One UI 7 / One UI 8 ומסומנים כ**משוערים**. Samsung משנה ניסוחים ומיקומים בין גרסאות, אזורים ושפות. אם לא מוצאים תפריט – השתמשו בחיפוש בראש מסך ההגדרות (סמל זכוכית מגדלת) עם המילים המודגשות.

המגביל של DISCIPLINE OS מגביל **רק אפליקציות שבחרתם**, **רק כשמשימות החובה שלכם פתוחות** (או בזמן שלב עבודה בפוקוס, אם הפעלתם זאת). כל ההרשאות ניתנות ידנית על ידכם, וכל אחת מהן ניתנת לביטול בכל רגע.

מצב ברירת המחדל הוא **גישה לנתוני שימוש + הצגה מעל אפליקציות**. שירות נגישות הוא **אופציונלי** לחלוטין.

---

## 0. הדרך הקצרה

באפליקציה: **מגביל ← הרשאות ומצב סוללה**. כל שורה מסבירה למה ההרשאה נחוצה, מציגה סטטוס (מאושר / חסר / אופציונלי) וכפתור שפותח את מסך ההגדרות המדויק. כשחוזרים לאפליקציה הסטטוס מתעדכן אוטומטית.

---

## 1. גישה לנתוני שימוש (נדרש)

**למה:** כדי לדעת איזו אפליקציה פתוחה כרגע. בלי זה המגביל לא יודע מתי להציג תזכורת. הנתונים נשארים במכשיר.

1. באפליקציה: הרשאות ← **גישה לנתוני שימוש** ← "פתח הגדרות".
2. במסך **"גישה לנתוני שימוש"** (Usage data access) – בחרו **DISCIPLINE OS**.
3. הפעילו את המתג **"התר גישה לנתוני שימוש"**.
4. חזרו לאפליקציה (חץ חזרה).

מסלול ידני משוער: הגדרות ← אפליקציות ← (⋮) **גישה מיוחדת** ← **גישה לנתוני שימוש** ← DISCIPLINE OS.

## 2. הצגה מעל אפליקציות אחרות (נדרש ב-Android 10+)

**למה:** Android לא מאפשר לאפליקציה לפתוח מסך מהרקע בלי ההרשאה הזו. בלעדיה נציג **התראה** במקום מסך תזכורת מלא.

1. באפליקציה: הרשאות ← **הצגה מעל אפליקציות אחרות** ← "פתח הגדרות".
2. בחרו **DISCIPLINE OS** והפעילו **"התר הצגה מעל אפליקציות אחרות"** (Appear on top).

מסלול ידני משוער: הגדרות ← אפליקציות ← (⋮) גישה מיוחדת ← **הצגה מעל אפליקציות אחרות**.

## 3. התראות (מומלץ)

**למה:** ההתראה הקבועה מראה שהמגביל פעיל ומה מצבו ("2 משימות חובה פתוחות • אפליקציות נבחרות מוגבלות" / "הכל פתוח"). היא תמיד גלויה – אנחנו לא מסתירים אותה.

- באפליקציה: הרשאות ← **התראות** ← אשרו בחלון של Android. אם סירבתם בעבר – ייפתח מסך ההתראות של האפליקציה.
- מסלול ידני משוער: הגדרות ← **התראות** ← **התראות אפליקציה** ← DISCIPLINE OS.
- אפשר להנמיך את ערוץ "מגביל אפליקציות" לשקט – אבל לא לכבות אותו אם רוצים לראות את המצב.

## 4. סוללה – "ללא הגבלה" ואפליקציות שאף פעם לא נרדמות (מומלץ מאוד ב-Samsung)

**למה:** One UI עוצר אפליקציות ברקע באגרסיביות. אם המגביל נעצר – הוא פשוט לא יעבוד עד שתפתחו את האפליקציה שוב.

המגביל חוסך סוללה בעצמו: **לא בודק כשהמסך כבוי**, **לא בודק כשאין מה להגביל**, בודק כל שנייה **רק** כשיש הגבלה פעילה, וכל 5 שניות כשהגבלה אפשרית (למשל בזמן שחרור זמני).

### 4א. מצב סוללה של האפליקציה
1. הגדרות ← **אפליקציות** ← **DISCIPLINE OS** ← **סוללה**.
2. בחרו **"ללא הגבלה"** (Unrestricted).
   - (באפליקציה: שורת הסוללה ← "פרטי האפליקציה" מוביל לשם.)

### 4ב. אפליקציות שאף פעם לא נכנסות למצב שינה
1. הגדרות ← **סוללה** (בגרסאות מסוימות: **טיפול במכשיר ← סוללה**) ← **הגבלות שימוש ברקע** (Background usage limits).
2. **"אפליקציות שאף פעם לא נכנסות למצב שינה"** (Never sleeping apps) ← **+** ← DISCIPLINE OS ← הוסף.
3. באותו מסך: כבו את **"העבר אפליקציות שאינן בשימוש למצב שינה"** (Put unused apps to sleep), או לפחות ודאו ש-DISCIPLINE OS לא מופיעה ב"אפליקציות במצב שינה" / "במצב שינה עמוקה".

### 4ג. אופטימיזציית סוללה של Android
באפליקציה: הרשאות ← **ללא הגבלת סוללה** ← "פתח הגדרות" פותח את **רשימת** אופטימיזציית הסוללה. בחרו "כל האפליקציות", מצאו את DISCIPLINE OS ובחרו **"אל תבצע אופטימיזציה"**.
> אנחנו בכוונה **לא** משתמשים בבקשה הישירה ("לאפשר לאפליקציה לפעול תמיד ברקע?") – היא דורשת הרשאה מוגבלת ורגישה מבחינת מדיניות Google Play.

### 4ד. "אופטימיזציה אוטומטית" / "סוללה מסתגלת"
- **טיפול במכשיר ← אופטימיזציה אוטומטית** (Auto optimization): עשויה להפעיל מחדש את המכשיר בלילה. לאחר הפעלה מחדש המגביל חוזר לבד (BOOT_COMPLETED). אין צורך לכבות.
- **סוללה ← הגדרות סוללה נוספות ← סוללה מסתגלת** (Adaptive battery): עלולה להגביל אפליקציות שלא נפתחות הרבה. אם המגביל נעצר לעיתים קרובות – הוסיפו אותו ל"אף פעם לא נרדמות" (4ב) או כבו סוללה מסתגלת.
- **מצב חיסכון בחשמל** (Power saving): עשוי להאט בדיקות רקע. זה תקין; המגביל ימשיך כשהמצב יכובה.

## 5. שירות נגישות (אופציונלי – רק אחרי גילוי נאות)

**מה הוא נותן:** זיהוי מיידי של האפליקציה שנפתחה (במקום בדיקה כל שנייה) – גם חסכוני יותר בסוללה.

**מה הוא קורא:** **רק** את שם החבילה (package name) של חלון שעבר לחזית (אירוע `TYPE_WINDOW_STATE_CHANGED`).
**מה הוא לא עושה:** לא קורא טקסט/תמונות/תוכן מהמסך (`canRetrieveWindowContent=false`), לא מקליד, לא לוחץ, לא מבצע מחוות, ושום דבר לא נשמר או נשלח מהמכשיר.

1. באפליקציה: מגביל ← שיטת זיהוי ← **"אופציונלי: שירות נגישות"**.
2. קראו את מסך **הגילוי הנאות** ולחצו **"אני מסכים/ה – פתח את הגדרות הנגישות"** (או "לא עכשיו" – אין לכך שום השלכה).
3. ב-One UI (משוער): הגדרות ← **נגישות** ← **אפליקציות מותקנות** (Installed apps) ← **DISCIPLINE OS – זיהוי אפליקציה פעילה** ← הפעילו.
4. Android יציג אזהרה כללית על שירותי נגישות – זו הודעת מערכת סטנדרטית.
5. ב-Android 13+ ייתכן שתראו "הגדרה מוגבלת" (Restricted setting) אם האפליקציה הותקנה מחוץ לחנות. במקרה כזה: הגדרות ← אפליקציות ← DISCIPLINE OS ← (⋮) **"התר הגדרות מוגבלות"**. זו החלטה שלכם בלבד.

אם שירות הנגישות פועל אבל לא אישרתם את הגילוי – השירות **לא עושה כלום**. בחירה חזרה במצב ברירת המחדל או "ביטול ההסכמה" גורמים לשירות לכבות את עצמו.

## 6. איך מבטלים הכל

הכל הפיך, בכל רגע, בלי לשאול אותנו:

| מה | איך (משוער) |
|---|---|
| לכבות את המגביל | באפליקציה: מגביל ← מתג "הפעלת המגביל" (לחיצה אחת, בלי חסימות) |
| השהיה זמנית | מגביל ← **מצב התאוששות** (1–72 שעות) |
| נתוני שימוש | הגדרות ← אפליקציות ← גישה מיוחדת ← גישה לנתוני שימוש ← DISCIPLINE OS ← כבוי |
| הצגה מעל אפליקציות | הגדרות ← אפליקציות ← גישה מיוחדת ← הצגה מעל אפליקציות אחרות ← כבוי |
| נגישות | הגדרות ← נגישות ← אפליקציות מותקנות ← DISCIPLINE OS ← כבוי |
| התראות | הגדרות ← התראות ← התראות אפליקציה ← DISCIPLINE OS |
| סוללה | הגדרות ← אפליקציות ← DISCIPLINE OS ← סוללה ← "אופטימלית" |
| הסרה | לחיצה ארוכה על האייקון ← הסר. **תמיד אפשרי.** |

## 7. מה האפליקציה לעולם לא תעשה

- לא תמנע הסרה, לא תשתמש ב-Device Admin, ולא תסתיר את האייקון או את עצמה.
- לא תחסום את ההגדרות, מסכי ההרשאות, מסך הבית, החייגן, שיחות חירום, SOS, הודעות SMS, התראות חירום (Cell Broadcast) או ממשק המערכת.
- לא תסתיר את ההתראה הקבועה של המגביל.
- לא תקרא תוכן מהמסך, לא תקליד ולא תלחץ בשמכם.
- לא תשלח את רשימת האפליקציות או נתוני שימוש מהמכשיר.
- לא תבטיח חסימה מוחלטת – ראו `docs/BLOCKER_LIMITATIONS.md`.
- לא תסרב ל**שחרור חירום** – הוא תמיד מאושר (לזמן מוגבל ונרשם ביומן שקוף).
