# RELEASE NOTES

## 0.1.0 (Preview) — 2026-11-04

גרסה ראשונה ("Preview"). **לא לשימוש בייצור**: האפליקציה טרם נבדקה על מכשיר פיזי או על אמולטור. ראו `TEST_REPORT.md`.

### חדש
- **משימות**: חובה/רשות, תתי-משימות, קטגוריות, עדיפויות, שעת יעד, חזרתיות יומית/שבועית/חודשית לפי תאריך מקומי (בטוח ל-DST), תזכורות, דחייה (עד 3 פעמים), דילוג עם סיבה, תלויות עם זיהוי מעגלים, אימות ביצוע (רשימת תתי-משימות / הערת רפלקציה / טיימר), היסטוריה מלאה, תכנון שבועי ומתזמן חכם (הצעה בלבד, בלי כתיבה אוטומטית).
- **חוסם אפליקציות**: בחירת אפליקציות מותקנות, הגבלה רק כשיש משימת חובה פתוחה, מסך חסימה עם המשימות שנותרו, שחרור זמני שקוף ומוגבל, שחרור חירום שתמיד זמין, מצב התאוששות (1–72 שעות), חבילות מוגנות שלעולם לא נחסמות. מצב ברירת מחדל: UsageStats + הצגה מעל אפליקציות. מצב Accessibility אופציונלי עם גילוי והסכמה.
- **ריכוז**: Pomodoro מותאם, הפסקה ארוכה כל N סשנים, התראה עם ספירה לאחור ופעולות, שורד הריגת תהליך (מבוסס timestamps).
- **AI Coach**: צ'אט בעברית עם streaming, מאמן דמו אופליין כברירת מחדל, ספק מרוחק דרך backend בלבד (opt-in), הצעות למשימות רק עם אישור מפורש, הגנות prompt injection, תקרת הודעות יומית.
- **גיימיפיקציה**: XP, רמות, 13 הישגים, רצף עם "הקפאה", סקירה שבועית תומכת.
- **סטטיסטיקה**: השלמה, שעות ריכוז, מגמה, קטגוריות, זמן מסך (עם הרשאה), גרפים נגישים.
- **הגדרות**: הרשאות עם הסבר, פרטיות AI, גיבוי/ייבוא JSON, מחיקת כל הנתונים, שפה, נגישות (ניגודיות גבוהה, הפחתת תנועה), חריגי חירום.
- **עיצוב**: Design System כהה מקורי, RTL מלא, תמיכה בגופן מוגדל, מצבי ריק/טעינה/שגיאה.

### אבטחה ופרטיות
- אין גיבוי ענן אוטומטי; אין מפתחות API באפליקציה; HTTPS בלבד; סודות ב-Keystore; אין לוג של תוכן אישי.

### ידוע / מגבלות
- אין חסימה מוחלטת (מגבלת Android). השהיית זיהוי של עד כשניה. יצרנים (כולל Samsung) עלולים לעצור שירותי רקע — ראו `docs/PERMISSIONS_S25_ULTRA.md`.
- מסד הנתונים לא מוצפן ברמת האפליקציה (מסתמך על הצפנת המכשיר).
- תרגום לאנגלית חלקי.
- AI מרוחק דורש פריסת backend והחלפת מזהה התקנה ב-JWT (לא מומש).
- Google Calendar, סנכרון Supabase ו-Push — מתוכננים בלבד.
