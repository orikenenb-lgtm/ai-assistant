## שלב B — בדיקה ב-Zelio Soft 2

### הכנה

1. מקלידים את התוכנית לפי `06_PLC_Logic/ZELIO_LADDER.md`.
2. מגדירים את הטיימרים. כדי לחסוך זמן בבדיקה אפשר לקצר זמנית את `T1` (חימום), ולתעד את זה.
3. עוברים למצב סימולציה.
4. **אין "שטח" בסימולציה של Zelio.** את מה שהציוד היה עושה מדמים ביד:
   - כש-`Q1` נדלק — מדליקים ידנית את `I6` (משוב המגען). כש-`Q1` כבה — מכבים את `I6`.
   - במצב רגיל מחזיקים דולקות את `I2` (STOP תקין) ואת `I4` (חירום משוחרר).
   - לחיצה על לחצן = הדלקה וכיבוי של הכניסה.

### טבלת הבדיקות

ממלאים את העמודה האחרונה: ✅ / ❌ + הערה. התרחישים זהים לתרחישים בסימולציית Python.
