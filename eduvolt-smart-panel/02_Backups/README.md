# גיבויים

התיקייה הזאת ריקה במאגר. על המחשב שלך הסקריפט `tools/Setup-EduVoltWorkspace.ps1` משתמש בה כך:

- `originals_<תאריך>` — **העתק** של קבצי EduVolt קיימים שנמצאו (רק עם `-BackupExistingEduVoltFiles`). המקור לא זז ולא משתנה.
- `incoming_<תאריך>` — קבצים חדשים מהמאגר שלא הועתקו כי קובץ שונה כבר קיים בסביבת העבודה. ממזגים ידנית.

כלל עבודה ב-EduVolt: **לפני כל שינוי משמעותי בפרויקט — שומרים עותק כאן עם תאריך ושעה בשם הקובץ.**
