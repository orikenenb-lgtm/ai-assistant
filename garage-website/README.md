# 🏍️ אתר למוסך אופנועים

תיקייה נפרדת לפרויקט האתר של המוסך שמטפל באופנוע של אורי.
הפרויקט הזה **לא קשור** ל-Kerem Orders — הוא רק יושב באותו ריפו כדי שיהיה נגיש מכל מקום.

## איך ממשיכים לעבוד מכל מכשיר

- **השיחה עם Claude** נשמרת בחשבון — פותחים אותה מהטלפון או מהמחשב דרך אפליקציית Claude או דרך האתר:
  https://claude.ai/code
- **הקבצים** שמורים ב-GitHub, בתיקייה הזאת (`garage-website/`).

## יומן שיחות

### 22.10.2026 — פתיחת הפרויקט
- אורי רוצה לבנות אתר לבעל מוסך שמתקן לו את האופנוע.
- שלב ראשון: נפתחה תיקייה נפרדת לפרויקט, כדי שאפשר יהיה להמשיך גם מהטלפון וגם מהמחשב.
- עדיין לא התחלנו לבנות.

## מידע שצריך לאסוף מבעל המוסך

- [ ] שם המוסך
- [ ] כתובת ושעות פתיחה
- [ ] טלפון / וואטסאפ
- [ ] אילו שירותים הוא נותן (טיפולים, תיקונים, צמיגים, טסט, חלקים וכו')
- [ ] לוגו ותמונות של המוסך ועבודות
- [ ] האם יש לו כבר דומיין, אינסטגרם או פייסבוק
- [ ] מה הכי חשוב לו: שיתקשרו, שיקבעו תור, או שיראו מחירים

## השלבים הבאים

1. לאסוף את המידע שלמעלה.
2. להחליט על מבנה האתר (דף אחד או כמה דפים).
3. לבנות, לבדוק בטלפון ובמחשב, ולהעלות לאוויר.
