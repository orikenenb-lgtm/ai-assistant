# Claudex Loop בפרויקטים גדולים

כשאורי מבקש משימת פיתוח גדולה — בכל פרויקט — השתמש ב-Claudex Loop:
Claude מתכנן, Codex בודק את התוכנית, הבנייה מתבצעת, ו-Codex בודק את הקוד הסופי.

## מה נחשב "גדול"

- פיצ'ר חדש שנוגע בכמה קבצים או בכמה שכבות (frontend, backend, מסד נתונים)
- פרויקט או אפליקציה חדשים מאפס
- שינוי ארכיטקטורה, refactor רחב, מיגרציה של מסד נתונים
- התחברות משתמשים, הרשאות, תשלומים, אינטגרציות חיצוניות

לא גדול: תיקון באג נקודתי, שינוי טקסט או עיצוב קטן, שאלה, הסבר, פקודה בודדת.

## מה לעשות

1. בדוק שהסקיל `claudex-loop:claudex-loop` זמין ברשימת הסקילים.
2. בדוק ש-Codex מוכן: `codex --version` ו-`codex login status`.
3. אם שניהם מוכנים — כתוב בשורה אחת שאתה מפעיל Claudex Loop, והפעל את הסקיל `claudex-loop:claudex-loop`.
   בקשה של אורי לבנות היא גם אישור לבנות; בקשה לתכנן בלבד — עצור אחרי תוכנית מאושרת.
4. אם התוסף או Codex חסרים — אל תעצור את העבודה. כתוב בשורה אחת מה חסר ואיך מתקנים, והמשך כרגיל עם תכנון, בדיקות וסקירה עצמית:
   - התוסף: `/plugin marketplace add chaseai-yt/claudex-loop` ואז `/plugin install claudex-loop@claudex-loop`
   - Codex: `npm install -g @openai/codex` ואז `codex login`
5. אם אורי אומר "בלי claudex" או "בלי לולאה" — לא להפעיל ולא להציע שוב באותה שיחה.
