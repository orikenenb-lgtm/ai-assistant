# התקנה והפעלה ב-Windows 11

יש שתי דרכים:

- **מתקין מוכן:** הכי פשוט.
- **הרצה מקוד המקור:** מתאים לפיתוח.

## א. מתקין מוכן (מומלץ)

1. ב-GitHub נכנסים ל-**Actions** ← הריצה האחרונה של **JARVIS Desktop** על הענף הנוכחי ← **Artifacts**. מורידים את `JARVIS-windows-x64`.
2. בתוך הקובץ יש:
   - `JARVIS Setup 0.1.0.exe`: מתקין.
   - `JARVIS-0.1.0-win.zip`: גרסה ניידת, בלי התקנה.
3. מריצים את המתקין. אם מופיעה האזהרה **"Windows protected your PC"**, לוחצים **More info** ← **Run anyway**. המתקין עוד לא חתום דיגיטלית; ראה ROADMAP-V2.
4. בסוף ההתקנה JARVIS נפתח. אייקון מופיע בשולחן העבודה ובתפריט התחל.

> **הערה:** התראות Windows (toast) עובדות בגרסה המותקנת, כי המתקין יוצר קיצור דרך בתפריט התחל עם מזהה האפליקציה. בגרסת ה-ZIP הניידת ייתכן שההתראות לא יופיעו. התזכורות עדיין יוצגו בתוך ה-HUD.

## ב. הרצה מקוד המקור

דרישות: **Node.js 22 LTS** (מ-nodejs.org) ו-**Git**.

פותחים PowerShell ומריצים:

```powershell
git clone https://github.com/orikenenb-lgtm/ai-assistant.git
cd ai-assistant
git checkout ccr-5bb40fe0-ybqwr9
cd jarvis-desktop
npm ci
npm run fetch-models
npm run build
npm start
```

מה עושה כל פקודה:

- `npm ci`: מתקין את הספריות בדיוק לפי `package-lock.json`.
- `npm run fetch-models`: מוריד את מודלי מילת ההפעלה ומאמת אותם ב-SHA-256.
- `npm run build`: בונה את main, preload ו-renderer.
- `npm start`: מפעיל את JARVIS.

### מצב פיתוח (טעינה חמה של הממשק)

```powershell
npm run dev
```

### בדיקות

```powershell
npm test
npx playwright test
```

- `npm test`: בדיקות יחידה.
- `npx playwright test`: בדיקות E2E על האפליקציה האמיתית. מריצים אותן אחרי `npm run build`.

### בניית מתקין במחשב שלך

```powershell
npm run dist:win
```

התוצרים נוצרים בתיקייה `release\`: `JARVIS Setup 0.1.0.exe` וקובץ ZIP.

## ג. הגדרה ראשונה (5 דקות)

פותחים את JARVIS ← כפתור ההגדרות (גלגל שיניים) או `Ctrl+,`.

### 1. פרויקט הגמר ו-EPLAN

**הגדרות ← תוכנות ופרויקטים**:

**EPLAN:**

- לוחצים **"זיהוי אוטומטי"**. JARVIS מחפש את `EPLAN.exe` בנתיבי ההתקנה הסטנדרטיים, למשל:
  ```
  C:\Program Files\EPLAN\Platform\<גרסה>\Bin\EPLAN.exe
  ```
- אם לא נמצא, לוחצים **"בחר קובץ…"** ובוחרים את `EPLAN.exe` ידנית.
- לוחצים **"אמת"**. צריך להופיע ✓.

**פרויקט הגמר:**

- בשורה "פרויקט הגמר" לוחצים **"בחר קובץ…"** ובוחרים את קובץ הפרויקט (בדרך כלל `.elk`).
- לוחצים **"אמת"**.
- מסמנים אותו כ**ברירת מחדל**.

**בדיקה:** לוחצים **"בדיקת פתיחה"**. Windows אמור לפתוח את הפרויקט ב-EPLAN.

> JARVIS **רק מבקש מ-Windows לפתוח** את הקובץ עם התוכנה המשויכת. הוא לא כותב לקובץ ולא משנה את הפרויקט.

**Spotify:**

- ברירת המחדל היא `spotify:`, ומתאימה לגרסה מה-Microsoft Store.
- אם Spotify מותקן כתוכנה רגילה, "זיהוי אוטומטי" ימצא את:
  ```
  %APPDATA%\Spotify\Spotify.exe
  ```

### 2. המוח — Claude

**הגדרות ← מוח**:

1. מדביקים מפתח API של Anthropic. יוצרים אותו ב-https://console.anthropic.com ← API Keys.
2. לוחצים **"שמור"**. המפתח נשמר מוצפן ב-Windows (DPAPI) ולא מוצג שוב.
3. לוחצים **"בדוק חיבור"**.

בלי מפתח JARVIS עובד ב**מצב מקומי** ומבין פקודות בסיסיות: פתיחת תוכנה או פרויקט, מצב מערכת, משימות ותזכורות פשוטות.

### 3. קול

ראה [VOICE-AND-AI-SETUP.md](VOICE-AND-AI-SETUP.md) להוראות מלאות. בקצרה:

- **תמלול:** מפתח OpenAI. ברירת המחדל היא `gpt-transcribe`.
- **הקראה בקול עברי טבעי:** Azure Speech, עם הקול `he-IL-AvriNeural`.
- **בלי שירותים בתשלום:** קול המערכת של Windows (Asaf).

### 4. מיקרופון

1. בפעם הראשונה ש-JARVIS מבקש מיקרופון, צריך לאפשר גישה.
2. אם המיקרופון חסום: **Windows ← הגדרות ← פרטיות ואבטחה ← מיקרופון**. מוודאים ש"גישה למיקרופון" ו"אפשר לאפליקציות שולחן עבודה לגשת למיקרופון" פועלים.
3. ב-JARVIS: **הגדרות ← קול ← בדיקת מיקרופון**. מד העוצמה צריך לזוז כשאתה מדבר.

## ד. שימוש יומיומי

- **לחיצה לדיבור:** כפתור המיקרופון, או `Ctrl+Alt+J` מכל מקום ב-Windows (ניתן לשינוי בהגדרות).
  - לוחצים, מדברים, וההקלטה נעצרת לבד אחרי שתיקה קצרה.
  - לחיצה נוספת עוצרת מיד.
- **עצירת הקראה:** כפתור העצירה, או `Esc` כשהחלון בפוקוס.
- **דיבור בזמן ש-JARVIS מדבר:** לחיצה על המיקרופון עוצרת את ההקראה ומתחילה להקשיב.
- **HUD קומפקטי:** הכפתור בשורת הכותרת, או מהמגש. אפשר לסמן "תמיד מעל חלונות".
- **סגירת החלון:** JARVIS עובר למגש המערכת וממשיך לתזכר. **יציאה מלאה:** קליק ימני על האייקון במגש ← "יציאה מלאה".

## ה. איפה נשמרים הנתונים

```
%APPDATA%\JARVIS\
```

| קובץ | מה הוא מכיל |
|---|---|
| `settings.json` | הגדרות, בלי מפתחות |
| `secrets.json` | מפתחות מוצפנים ב-DPAPI. ניתנים לפענוח רק במשתמש ה-Windows שלך |
| `jarvis.db` | משימות, תזכורות, היסטוריה ונתוני שימוש (SQLite) |
| `logs\` | יומני אירועים מצומצמים, נשמרים 7 ימים |

מחיקה: **הגדרות ← פרטיות ושימוש ← "מחק הכול"**.
