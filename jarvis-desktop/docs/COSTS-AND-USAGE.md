# שירותים בתשלום ומעקב שימוש

JARVIS עובד גם בלי שום שירות בתשלום, אבל עם יכולות מוגבלות:

- **פענוח מקומי:** פקודות בסיסיות בעברית.
- **קול המערכת של Windows:** הקראה בקול Asaf.
- **בלי תמלול:** אין דיבור, רק הקלדה.

כדי לקבל הבנה חכמה, דיבור והקראה טבעית צריך מפתחות API. **לא מופיע כאן מחיר חודשי**, כי הוא תלוי בכמות השימוש שלך. במקום זה: איפה מחירי היחידה מפורסמים, ואיך לעקוב אחרי השימוש בפועל.

## חשבון פשוט לפני שמתחילים

אם תרצה להעריך עלות, זה מה שקורה בבקשה קולית רגילה, כמו "תפתח את פרויקט הגמר שלי":

1. **תמלול:** 2–5 שניות אודיו.
2. **Claude:** 1–3 קריאות קצרות. המודל מציע כלי, הכלי רץ, והמודל מנסח תשובה. כל קריאה כוללת את הוראות המערכת ואת הגדרות הכלים, אבל הן נשמרות במטמון (prompt caching), כך שהחלק החוזר זול בהרבה.
3. **הקראה:** בערך 30–80 תווים.

**ניתוח צילום מסך:**

- הצילום מוקטן ל-1920 פיקסלים בצד הארוך (ברירת מחדל).
- תמונה כזו היא בערך 2,700 טוקני קלט, לפי האלגוריתם בתיעוד של Anthropic.
- זו הפעולה היקרה ביותר ב-JARVIS. לכן היא מתבצעת רק כשאתה מבקש במפורש: לחיצה על כפתור המצלמה, או בקשה בשיחה שמציגה דיאלוג אישור.

## איך עוקבים אחרי השימוש

### בתוך JARVIS

**הגדרות ← פרטיות ושימוש ← טבלת שימוש.** JARVIS רושם מקומית, ב-SQLite, את מה שהספקים מחזירים בפועל:

- **Claude:** טוקני קלט ופלט מכל תשובה. הקלט כולל גם טוקנים שנכתבו למטמון או נקראו ממנו (`input_tokens` + `cache_creation_input_tokens` + `cache_read_input_tokens`). לכן המספר גבוה מהחיוב בפועל: טוקנים שנקראים מהמטמון מחויבים בתעריף מוזל.
- **תמלול:** שניות אודיו.
- **הקראה:** מספר תווים.

הטבלה מסוכמת להיום ולחודש הנוכחי, לפי ספק ומודל. אפשר למחוק אותה ב"מחק הכול" (הגדרות ← פרטיות ושימוש).

### בלוחות הבקרה של הספקים

הנתונים הרשמיים לחיוב נמצאים שם:

- **Anthropic:** Console ← Usage / Cost. אפשר גם להגדיר מגבלת הוצאה (spend limit) בהגדרות הארגון.
- **OpenAI:** platform.openai.com ← Usage. אפשר גם להגדיר תקציב ו-alerts.
- **Azure:** Azure Portal ← Cost Management ← Cost analysis. מומלץ להגדיר Budget עם התראה במייל.

## איך שולטים בעלות

- **עומק חשיבה (effort) של Claude:** ברירת המחדל היא `low`. היא מספיקה לפקודות קצרות, והיא גם הכי מהירה. העלה ל-`medium` רק אם ההבנה לא מספיקה לך.
- **מודל:** אפשר לבחור דגם זול יותר בהגדרות ← מוח. ההחלטה שלך: ברירת המחדל היא הדגם החזק.
- **הקראה בחינם:** עבור לקול המערכת. הוא פחות טבעי, אבל חינמי ומקומי.
- **בלי Claude:** במצב "מקומי בלבד" (הגדרות ← מוח) JARVIS לא שולח בקשות ל-Claude, ומבין רק את הפקודות הבסיסיות. **שים לב:** זה משפיע רק על המוח. הקלטה קולית עדיין נשלחת לספק התמלול שבחרת. כדי שגם הקול יישאר במחשב, בחר תמלול "שרת מקומי תואם OpenAI" והקראה "קול מערכת".
- **צילומי מסך:** רק לפי בקשה מפורשת. אפשר להקטין את "רזולוציה מרבית לצד הארוך (פיקסלים)" (הגדרות ← מסך) כדי לחסוך טוקנים.
