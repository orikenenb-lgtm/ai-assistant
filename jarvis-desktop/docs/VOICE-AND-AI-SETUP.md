# הגדרת ספקי AI, קול ומילת הפעלה

כל המפתחות נשמרים מוצפנים ב-Windows (Electron safeStorage ← DPAPI), ונגישים רק לתהליך הראשי של JARVIS. הממשק רואה רק אם מפתח מוגדר, לא את הערך שלו.

## למה נבחרו הספקים האלה

הבחירה מבוססת על תיעוד רשמי עדכני (אוקטובר 2026). פירוט המקורות נמצא ב-REPORT.md.

| רכיב | בחירה | הנימוק |
|---|---|---|
| מוח | Claude `claude-opus-5-5` (Anthropic) | tool calling עם `strict: true`, ניתוח תמונה (vision) ועברית טובה. ברירת המחדל `effort: low` למהירות |
| תמלול | OpenAI `gpt-transcribe` | המודל העדכני של OpenAI לתמלול קבצים. הוא היחיד שבדקתי שמקבל גם כמה שפות (`languages: he, en`) וגם מילות מפתח (`keywords`), וזה מתאים לעברית עם שמות תוכנות באנגלית. המודלים הקודמים (`whisper-1`, `gpt-4o-transcribe`) יוסרו ב-26.2.2027 לפי הודעת OpenAI |
| הקראה | Azure AI Speech: `he-IL-AvriNeural` (גבר) / `he-IL-HilaNeural` (אישה) | הקולות העבריים הנוירליים הטבעיים היחידים שמתועדים רשמית. ל-OpenAI TTS יש תמיכה בעברית, אבל הקולות שלו מותאמים לאנגלית |
| הקראה חינמית | קול המערכת של Windows (Asaf) | מקומי, חינם, פחות טבעי |
| מילת הפעלה | Porcupine ("Jarvis"), או openWakeWord ("Hey Jarvis") | ראה בהמשך |

## 1. Claude (מוח)

1. נכנסים ל-https://console.anthropic.com ← **API Keys** ← **Create Key**.
2. מומלץ להגדיר מגבלת הוצאה (spend limit) בהגדרות הארגון.
3. ב-JARVIS: **הגדרות ← מוח ← "מפתח Claude"** ← מדביקים ← **שמור מפתח** ← **בדוק חיבור**.

אפשרויות במסך הזה:

- **מודל:** ברירת המחדל `claude-opus-5-5`. החלפה לדגם אחר היא בחירה שלך.
- **עומק חשיבה (effort):**
  - `low`: מהיר וזול, ומספיק לפקודות.
  - `medium` / `high`: יותר "חשיבה" לבקשות מורכבות.
- **מצב מוח:**
  - "אוטומטי": Claude כשיש חיבור, ופענוח מקומי כשאין.
  - "מקומי בלבד": בלי Claude. משפיע רק על המוח: התמלול וההקראה ממשיכים לפי הספקים שבחרת בהגדרות ← קול.

> **אם אין חיבור לאינטרנט, או ש-Claude לא זמין:** JARVIS מנסה לבצע את הבקשה במצב מקומי, אם היא פשוטה, ואומר לך שזה מה שקרה.

## 2. תמלול (Speech-to-Text)

### אפשרות א': OpenAI (ברירת מחדל)

1. נכנסים ל-https://platform.openai.com ← **API keys** ← יוצרים מפתח.
2. ב-JARVIS: **הגדרות ← קול ← ספק תמלול: OpenAI** ← מדביקים את המפתח ← **שמור מפתח**.
3. לוחצים **"בדיקת תמלול"**, אומרים משפט קצר, ובודקים שהטקסט נכון.

מה JARVIS שולח לשירות:

- רק את קטע ההקלטה מלחיצה לדיבור. לרוב 2–15 שניות, בפורמט WAV 16kHz.
- `languages: he, en`.
- רשימת שמות התוכנות שהגדרת, כ-`keywords`.

### אפשרות ב': Azure Speech

1. ב-Azure Portal יוצרים משאב **Speech**. עדיף אזור באירופה, למשל `westeurope`.
2. מעתיקים את **Key 1** ואת ה-**Region**.
3. ב-JARVIS: **הגדרות ← קול ← ספק תמלול: Azure** ← מפתח ואזור.

מגבלות:

- עד 60 שניות בבקשה (REST לקטעים קצרים).
- שפה: `he-IL`.

### אפשרות ג': שרת מקומי (בלי ענן)

כל שרת שחושף ממשק תואם OpenAI בכתובת `/v1/audio/transcriptions` יעבוד, בתנאי שהוא **במחשב הזה או ברשת המקומית** (`localhost`, ‏`127.x`, ‏`192.168.x`, ‏`10.x`, ‏`172.16–31.x`). כתובת באינטרנט נחסמת, כדי שהשדה הזה לא ישמש לשליחת הקלטות החוצה:

- **speaches** (MIT) עם המודל `ivrit-ai/whisper-large-v3-turbo-ct2`. מתאים כשיש כרטיס NVIDIA.
- **whisper.cpp server** (MIT) עם מודל GGML של ivrit-ai. מתאים ל-CPU או ל-Vulkan.

הרצה של whisper.cpp:

```powershell
whisper-server.exe -m ggml-ivrit-large-v3-turbo-q8_0.bin -l he --host 127.0.0.1 --port 8000 --request-path /v1/audio --inference-path /transcriptions
```

ב-JARVIS:

- **ספק:** "שרת מקומי תואם OpenAI".
- **כתובת:**
  ```
  http://127.0.0.1:8000/v1
  ```
- **מודל:** שם המודל בשרת. ב-whisper.cpp אפשר להשאיר ריק.

> **לא נבדק כאן:** איכות התמלול המקומי של ivrit-ai על המחשב שלך, ומהירות התגובה (תלויה ב-GPU). כדאי למדוד על 20–30 פקודות שלך.

## 3. הקראה (Text-to-Speech)

### Azure (מומלץ לעברית טבעית)

**הגדרות ← קול ← ספק הקראה: Azure**:

1. מפתח Azure Speech (אותו מפתח של התמלול).
2. אזור.
3. קול: `he-IL-AvriNeural` או `he-IL-HilaNeural`.
4. לוחצים **"השמע דוגמה"**.

### קול המערכת (חינם)

אם לא נמצא קול עברי, מתקינים אותו ב-Windows: **הגדרות ← זמן ושפה ← דיבור (Speech) ← "הוסף קולות" ← עברית**. אחרי ההתקנה מפעילים מחדש את JARVIS ובוחרים **Microsoft Asaf**.

> **מגבלה:** בקול המערכת אין ל-JARVIS גישה לאות האודיו. לכן ה-HUD מציג פעימה ולא waveform. זה בכוונה, כדי לא להציג גל מזויף.

## 4. מילת הפעלה

הזיהוי מתבצע **מקומית** במחשב. שום קול לא נשלח לענן לצורך זיהוי מילת ההפעלה. האזנה למילת ההפעלה **כבויה כברירת מחדל**. כשהיא פעילה, ה-HUD מציג "האזנה למילת הפעלה (מקומית)", וכשההקלטה פעילה מופיע "מיקרופון פעיל".

### Porcupine — המילה "Jarvis" (מומלץ אם רוצים מילה אחת)

1. נרשמים ל-https://console.picovoice.ai ומעתיקים את ה-**AccessKey** החינמי.
2. בודקים את התנאים העדכניים של החשבון החינמי ב-https://picovoice.ai/pricing. לא הצלחתי לאמת אותם מסביבת הבנייה.
3. ב-JARVIS: **הגדרות ← מילת הפעלה** ← מנוע: **Porcupine** ← מדביקים AccessKey ← מפעילים.

מה צריך לדעת:

- Porcupine **מאמת את המפתח מול שרתי Picovoice**, ולכן צריך אינטרנט בהפעלה. **האודיו עצמו לא נשלח.**
- המנוע רץ בתהליך הראשי של JARVIS, והמפתח לא מגיע לממשק.
- Porcupine צריך את **Microsoft Visual C++ Redistributable 2015–2022 (x64)**. אם הוא חסר, JARVIS יציג הודעה מתאימה.

### openWakeWord — "Hey Jarvis" (בלי מפתח)

- בלי הרשמה ובלי אינטרנט.
- צריך לומר **"Hey Jarvis"**. בבדיקה, "Jarvis" לבד קיבל ציון 0.29, מתחת לסף 0.5.
- רישיון המודל: **CC BY-NC-SA 4.0**, לשימוש אישי ולא מסחרי.

### כיוונון

- **רגישות** גבוהה יותר = פחות פספוסים, אבל יותר הפעלות שווא.
- בזמן ש-JARVIS מדבר, מילת ההפעלה מושהית כדי שלא יפעיל את עצמו. היא חוזרת 0.6 שניות אחרי שהוא מסיים.
- בזמן שדיאלוג אישור פתוח, מילת ההפעלה מושהית. כך דיבור ברקע לא יאשר פעולה.

### אם מילת ההפעלה לא עובדת

לחיצה לדיבור ממשיכה לעבוד כרגיל, וה-HUD מציג את הסיבה. לדוגמה: מפתח לא תקין, אין מיקרופון או אין הרשאה.

JARVIS מזהה גם תקלה שקורית אחרי שההאזנה התחילה: מיקרופון שנותק, 3 שניות בלי אודיו, או שגיאה במנוע. במקרה כזה:

- הוא מנסה שוב לבד אחרי 5 שניות, 30 שניות ו-2 דקות, ואז עוצר.
- חיבור מיקרופון מחדש מפעיל ניסיון מיידי.
- אפשר לנסות שוב ידנית: לחיצה על החיווי הכתום ב-HUD, או "נסה שוב" בהגדרות ← מילת הפעלה.

## 5. המשך האזנה אחרי תשובה

אם מפעילים "המשך האזנה אחרי תשובה" (הגדרות ← קול), JARVIS מקשיב שוב 0.6 שניות אחרי שסיים לדבר, כדי שתוכל להמשיך בלי ללחוץ. כדי שזה לא יהפוך להקלטה רציפה, יש לכל היותר 2 האזנות המשך ברצף. כל לחיצה, קיצור מקשים או מילת הפעלה מאפסים את הספירה.
