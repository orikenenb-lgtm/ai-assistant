# רשימת המשך ל-V2

V1 נבנה כך שאפשר להרחיב אותו בלי לשבור את הבסיס. כל כלי חדש עובר באותו צינור: סכמת zod קשיחה, מדיניות הרשאות, אישור חד-פעמי לפעולות רגישות ויומן פעולות. כל אחסון עובר דרך ממשקי Repository.

## 1. טלפון — Galaxy S25 Ultra

- **אפליקציית מלווה (Android, Kotlin) שמדברת עם JARVIS ברשת הביתית בלבד:**
  - צימוד ראשוני בקוד QR.
  - מפתח שנשמר ב-Android Keystore.
  - TLS עם הצמדת תעודה (pinning).
- **שימושים:**
  - "Jarvis" מהטלפון כשאתה לא ליד המחשב.
  - קבלת תזכורות גם כשהמחשב כבוי, אחרי שהן מסונכרנות לענן (ראה סעיף 4).
  - שליטה מרחוק בפעולות שכבר קיימות: מצב מערכת, משימות.
- **פעולות עם השפעה:** אישור ב-JARVIS עדיין חובה (מחשב או טלפון), עם אותו מנגנון אישור חד-פעמי שקשור לפרמטרים.

## 2. שעון — Galaxy Watch

- **Tile או Complication עם:**
  - המשימה הבאה.
  - התזכורת הבאה.
  - כפתור "דבר עם JARVIS" שמעביר את ההקלטה דרך הטלפון.
- **רטט לתזכורות** (דרך אפליקציית הטלפון).

## 3. בית חכם

- **חיבור דרך Home Assistant (API מקומי):** לא מאות אינטגרציות, אלא רשימה מאושרת של ישויות (entities) שהמשתמש בוחר.
- **הרשאות לפי רמות:**
  - קריאת מצב: ללא אישור.
  - הדלקה וכיבוי של תאורה: ללא אישור, בהגדרה.
  - מנעולים, חימום וכל דבר בטיחותי: אישור מפורש בכל פעם.
- **שליטה בלוח חשמל:** **לא תיכנס בלי הפרדה פיזית ואישור כפול.** זו מערכת בטיחותית.

## 4. סנכרון זיכרון (Supabase)

הבסיס כבר קיים ב-V1:

- **עמודות סנכרון:** `updated_at` ו-`deleted` (tombstone) בטבלאות `tasks` ו-`reminders`.
- **ממשק:** `SyncAdapter` ב-`src/main/db/sync.ts`.

מה צריך להוסיף:

- **הטבלאות:** `tasks` ו-`reminders`, עם RLS לפי `auth.uid()`. סנכרון `history` (אופציונלי) ידרוש קודם להוסיף לה `updated_at` ו-`deleted`.
- **התחברות:** Supabase Auth עם magic link. ה-refresh token נשמר ב-safeStorage.
- **סנכרון:** last-write-wins לפי `updated_at`, ומחיקה רכה.
- **הצפנה בצד הלקוח:** לשדות טקסט חופשי, לפני העלאה.
- **תזכורות בענן:** Edge Function ששולחת push לטלפון. כך תזכורת תגיע גם כשהמחשב כבוי, וזו המגבלה העיקרית של V1.

## 5. שיפורי קול

- **תמלול בזמן אמת (streaming):** `gpt-live-transcribe` או Azure real-time, כדי לקצר את ההמתנה.
- **TTS בזרימה:** ההקראה מתחילה כבר מהמשפט הראשון.
- **מילת הפעלה עברית מותאמת אישית:** אימון מודל ייעודי, למשל ב-openWakeWord, על הקול שלך.
- **מילון הגייה:** לשמות באנגלית בתוך עברית (SSML phoneme / sub alias ב-Azure).

## 6. EPLAN

- **קריאה בלבד:** סיכום פרויקט, למשל רשימת עמודים ודוחות, דרך יצוא קבצים שהמשתמש מפעיל.
- **בלי לשנות את הפרויקט:** כל שינוי בפרויקט EPLAN דורש החלטה נפרדת, גיבוי ואישור מפורש.

## 7. תשתית

- **חתימת קוד (code signing) למתקין:** מונעת את אזהרת SmartScreen.
- **עדכונים אוטומטיים:** electron-updater עם חתימה.
- **מעבר ל-Electron 45/46** כשהם יציבים. הקוד כבר משתמש ב-safeStorage האסינכרוני.

- שליחת הודעות אוטונומית.

- הרצת פקודות shell שרירותיות.
