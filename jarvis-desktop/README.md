# J.A.R.V.I.S — עוזר אישי קולי ל-Windows 11

JARVIS הוא אפליקציית Desktop (Electron + React + TypeScript). אתה מדבר אליו בעברית, הוא מבין, מבצע פעולות מורשות במחשב ועונה בקול. לצידו מופיע HUD עתידני קטן בהשראת Iron Man.

> **הדרך המהירה:** הורד את המתקין מ-GitHub Actions והפעל אותו. ההוראות ב-[docs/SETUP-WINDOWS.md](docs/SETUP-WINDOWS.md).

## מה הוא יודע לעשות (V1)

| יכולת | דוגמה | איך זה עובד |
|---|---|---|
| שיחה בקול ובטקסט | "Jarvis, מה יש לי לעשות היום?" | לחיצה לדיבור או `Ctrl+Alt+J` ← תמלול ← Claude עם כלים ← תשובה קולית |
| פתיחת תוכנות | "תפתח EPLAN", "פתח Spotify" | רק תוכנות מהרשימה המאושרת בהגדרות |
| פתיחת פרויקט | "תפתח את פרויקט הגמר שלי" | פתיחה דרך שיוך הקבצים של Windows. הפרויקט לא משתנה |
| משימות | "תוסיף משימה לסיים את השרטוט" | נשמרות מקומית (SQLite) |
| תזכורות | "תזכיר לי מחר בשמונה בבוקר לפתוח את הפרויקט" | לפי Asia/Jerusalem, כולל שעון קיץ. מבקש הבהרה כשהשעה עמומה |
| ראיית מסך | "תסתכל על המסך ותגיד לי מה לא בסדר" | צילום רק באישור, עם חיווי. לא נשמר. ניתוח בלי כלים |
| מצב מערכת | "Jarvis, מצב מערכת" | מעבד, זיכרון, דיסק, סוללה וחיבור לשירותים. רק נתוני אמת, בלי טמפרטורות |
| מילת הפעלה | "Jarvis" או "Hey Jarvis" | זיהוי מקומי, כבוי כברירת מחדל |

**בלי מפתחות ובלי אינטרנט** JARVIS עדיין:

- פותח תוכנות ופרויקטים.
- שומר משימות ותזכורות.
- מציג מצב מערכת.

את כל זה הוא עושה דרך פענוח מקומי של פקודות בסיסיות בעברית.

## התקנה והרצה מקוד המקור

```powershell
cd jarvis-desktop
npm ci
npm run fetch-models
npm run build
npm start
```

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | מצב פיתוח (Vite + Electron) |
| `npm test` | בדיקות יחידה (vitest) |
| `npx playwright test` | בדיקות E2E על האפליקציה האמיתית. מריצים אחרי `npm run build` |
| `npm run typecheck`, `npm run lint` | בדיקת טיפוסים ו-lint |
| `npm run dist:win` | בניית מתקין NSIS ו-ZIP ל-Windows (בתיקייה `release\`) |

## עקרונות אבטחה בקצרה

- **הממשק מבודד** (contextIsolation, sandbox, CSP קשיח). כל IPC מאומת לפי השולח ולפי סכמת zod.
- **אין כלי shell.** תוכנות נפתחות רק מרשימה מאושרת, בלי מעטפת פקודות.
- **פעולות רגישות** דורשות אישור חד-פעמי שקשור לפרמטרים ופג תוך דקה.
- **הוראות מצילומי מסך** אינן הוראות. כל פעולה אחריהן דורשת אישור מפורש.
- **מפתחות מוצפנים ב-DPAPI** ולא נחשפים לממשק.
- **לוגים מצומצמים.** אפשר למחוק את ההיסטוריה.
